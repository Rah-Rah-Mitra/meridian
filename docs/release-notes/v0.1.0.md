First release: a geo-aware, privacy-conscious edge search appliance in Rust,
sized for a Raspberry Pi 5 and scaling to edge servers without redesign.

## Highlights

- **Hybrid search**: SearXNG metasearch + local Tantivy BM25 + USearch ANN
  (model2vec static embeddings), RRF fusion, LTR ranking with explainable
  `rank_signals` and per-stage `timings`; optional INT8 cross-encoder rerank
  (`mode=deep`).
- **Three egress lanes per request**: `direct` · `region:<id>` (WireGuard
  source-IP binding with egress-IP verify-or-refuse) · `anon` (Tor via
  embedded Arti behind Meridian's own SOCKS5 isolation front-end —
  fail-closed at four layers, never a silent direct fallback).
- **Geo-aware**: H3 res-7 index cells via an offline GeoNames gazetteer,
  geo/time-filtered search, `/v1/geo/heatmap`; opt-in GDELT regional trends
  (`/v1/trends`) with 90-day retention and a PageRank-derived domain prior.
- **Privacy guardrails as hard requirements**: no query logging, client IPs
  never persisted, bounded metric cardinality, real deletion via
  `POST /v1/forget` (lexical + vector + caches + re-ingest tombstone), CI
  privacy smoke + egress invariant suites. See `docs/privacy.md`.
- **Appliance discipline**: `FROM scratch` multi-arch images (~75 MB),
  read-only containers, single mutable volume, resource-shedding ladder,
  every budget in `docs/plan/02-budgets.md` validated on a Pi 5.
