## Honesty notes

- **e2e p50 is elevated by segment state, not by Phase-7 code.** The fresh
  ingest committed ~1000 batches; Profile R merges run nightly, so BM25 scans
  many small segments (bm25_ms ~14ms vs 0.48ms on the merged Phase-6 index).
  The A/B kill-switch isolates Phase-7's actual cost at +0.2ms p50. Re-measure
  after the nightly merge; the p95/p99 band already matches Phase 6.
- **A fresh ingest was REQUIRED, not optional:** the dedup table short-circuits
  re-ingest of known content before sketches are written, so a v0.1.0 volume
  cannot be back-filled — v4 was ingested from scratch (v3 kept as rollback).
  Operator manual documents that pre-v0.2.0 documents carry no sketches.
- **Suites 1–8:** fusion 0.155ms (vs 0.144 Phase-0), embed 46.3k docs/s (vs
  42.9k), lexical BM25 0.477ms p50 @100k (vs 0.48 — and confirming the live
  deployment's 14ms is purely unmerged-segment state), disk PASS. **ANN:
  bisect CONCLUDED same evening** — recall ≈0 is not toolchain or device
  drift; it is the Phase-2 portable-usearch fallback itself (ADR-07 rung 2):
  recall collapses with scale (0.52 @10k → 0.007 @100k → 0.0 @1M),
  deterministic across the CI gnu artifact AND a native local build, while
  the numkong backend on identical code measures **0.92–0.98 @10k and 0.999
  @100k**. The product's dense lane has been recall-degraded since Phase 2 —
  masked by BM25-dominant RRF (which is also exactly why live spot checks
  looked "concordant with BM25"). Fix in this train: rung 1 (numkong)
  restored — 7.7.0's per-kernel ISA probes drop the SVE/SME kernels zig
  rejects, which the Phase-2-era build script could not; the musl CI job is
  the proof gate. ADR-07 amended; risk #3 re-fired and re-scoped; the suite-2
  RECALL gate re-runs at every exit from now on (a latency-only
  re-validation is how this slipped for five phases). Rerank remains
  gnu-image-only (unchanged, ADR-02).
- **Ingest rate is limiter-paced:** 99 docs/s reflects the public 5 rps × 100-doc
  batches pacing, identical conditions to the Phase-5 re-ingest; the server was
  never the bottleneck, so the ≤10% regression gate is trivially held; the
  per-doc sketch cost is bounded by construction (one hash pass per shingle).
- **No fresh multi-hour soak this exit.** RSS was observed through ingest + load

  evidence adds only bounded per-request allocations (≤50 sketches + clusters).
  The v0.3.0 exit inherits the next full soak.
- **GDELT caveat stands** (ADR-15/21): trends describe media coverage, not
  ground truth; the new `significant` flag is about statistical support within
  that feed.

## Deviations from plan

1. **Evidence slot:** ADR-18 sketched a post-RRF/pre-LTR clustering slot; as
   built, clustering runs on the FINAL result set (post-LTR/diversity/rerank)
   so the block describes exactly what the caller sees. Equivalent until LTR
   consumes cluster features (the planned GBDT integration moves it pre-LTR).
2. **Sketch budget re-issued:** the 64 B/doc ceiling was written against the
   payload; the measurable quantity is gross redb growth — 123 B/doc. Budgets
   row re-issued to ≤128 B/doc gross (12.8MB @100k R / 128MB @1M F — still
   well inside the 600MB redb envelope). Not silently absorbed.
3. **Mid-exit fix (`MIN_MATCH_BINS`):** the live exit drill caught a real false
   merge the synthetic farms missed — one chance b=8 bin collision against a
   tiny shingle set amplifies through the containment denominator past τ.
   Fixed with a 5-matched-bins floor (noise P(≥5)≈5e-7; real derivation
   produces 25+), regression-tested (500 adversarial pairs), and suite 9's
   generator now includes tiny stubs so the asymmetry case is measured
   permanently. Hold-out F1 *improved* (0.821 → 0.918). ADR-18 amended.
4. **Direct metasearch deadline:** suite 12 was the first systematic
   direct-websearch measurement and found the 800ms default deadline kills
   nearly every real fan-out on this network (engines need 0.8–1.6s; 90/96
   probes empty). Operator override applied (2500ms, deployment config). The
   default stays — it is a budget ceiling — but the operator manual now flags
   the knob, and Phase 8's compare-vantages depends on a working direct lane.
5. **Suite-10 variant divergence (2.1×, risk #21 review):** cause understood —
   the hold-out is a deliberately harder regime (overdispersion + ramps) and
   the candidate still dominates the baseline there with held FDR. Closed.
