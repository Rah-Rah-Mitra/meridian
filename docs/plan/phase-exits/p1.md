## Measurement notes (honesty section)

- First latency sample was polluted by the rate limiter (~170/200 responses were
  429s → fake 0.6ms p50). Re-measured with status-aware sampling and the limiter
  lifted via an uncommitted override; the gate script now counts only 200s.
- **Metasearch latency floor is SearXNG's slowest engine**, not our deadline:
  real engines need ~1.5–3.5s (duckduckgo rate-suspends shared IPs; wikidata
  times out). Committed mitigation: `outgoing.request_timeout: 1.5` in the
  searxng config. The §6.3 ≤900ms metasearch p50 stays PROVISIONAL until the
  Phase-3 bandit picks fast engine subsets; demo run with a 4s deadline returned
  blended local+web results with no degradation flag (searx_ms 3005).
- Bugs caught by live smoke, fixed in-phase: figment env provider ingesting
  `MERIDIAN_BEARER_TOKEN` (secrets now excluded from the config layer); silent
  local-serve under `lane=anon&scope=both` when searx disabled (now 503
  fail-closed; `lane_effective: "local-only"` for no-egress requests).
