## Honesty notes

- **The jitter default is honest but weak under the default request ceiling.**
  Suite 12b's first live compares 504'd: the 30s default jitter window cannot
  fit inside the 12s `server.request_timeout_ms`. The orchestrator now clamps
  the effective jitter to what the ceiling leaves (well under a second at
  defaults), and privacy.md says plainly that meaningful timing decorrelation
  requires raising the ceiling (or the Phase-10 async compare). The jitter
  knob is not silent security theater.
- **The 12b gate found a fabrication bug before it shipped.** The first gate
  attempt returned 48/48 compares with JSD exactly 0.0 — both halves empty
  (sidecars down after a service-scoped redeploy) and `jsd(∅,∅)=0` reads as
  "no divergence": fabricated agreement. Compare now fails closed when either
  half has zero web results, checking the direct half BEFORE the anon
  dispatch (no Tor circuit spent on a doomed comparison); inv17 pins it.
  Operational lesson recorded: never service-scoped `up -d`; lane status ≠
  sidecar health.
- **QPP's ρ=0.256 is modest by design** (ADR-23 chose two cheap, explainable
  predictors over calibration machinery; the gate was set accordingly at
  0.25). ECE 0.065 is reported as a diagnostic, not a gate. The confidence
  block is a hint, not a probability — api.md says so.
- **Suite 13 ran on the healed dense lane** (numkong, v5 volume) and closed a
  P7 carry-forward: hybrid nDCG@10 0.4184 ≥ BM25 0.4099 (MRR 0.3544 vs
  0.3436) on the synthetic known-item set — the healthy-ANN hybrid ordering
  holds.
- **Three invalid runs of suite 13b are documented, not hidden** (bench doc):
  URL-collapsing copy titles (the tell: alpha == nDCG exactly), a
  string-replace patch that silently missed, and a generator whose query
  words leaked into ≤40 unjudged background docs. The final design fixed
  construct validity (exclusive df=3 words, copies retrievable
  post-truncation, production-faithful MMR text, gate on the BM25
  web-head proxy with the hybrid head as diagnostic) — and the verdict on
  that valid design is the FAIL recorded above.
- **Suites 1–8 standing gates:** re-validated at the P7 exit ~24h before this
  note on the same engine code; Phase 8's deltas since (flag-gated compare,
  sub-ms QPP, jitter clamp, MMR withdrawal, default-off decision log) do not
  touch the embed/ANN/lexical/disk paths. Re-run at this exit on the CI
  release-bench artifact (device): fusion **0.166ms p50** (P0 baseline
  0.144, P7 0.155), evidence, synfarm, spike, ope — **all gates PASS**. The
  heavy device suites (embed/ann/lexical/disk/thermal) stand on yesterday's
  P7-exit run.
- **The soak ran with concurrent development load, declared rather than
  hidden:** Phase-9 code was written and incrementally compiled on the same
  box during the window (the user-directed workflow). The p99 minute-maxima
  show those bursts (max 3.3s in compile minutes vs 33ms median); RSS,
  error counts, and the plateau verdict are load-composition-independent —
  if anything a plateau held under soak + dev load is the stronger claim.
- **Compare-mode availability over Tor is environmental, and tonight proved
  it.** Exit probing hit windows where every compare 503'd: search engines
  CAPTCHA/403 Tor exit IPs, searxng suspends the failing engines
  (TooManyRequests, suspended_time compounding), and aggressive probing makes
  it worse — the morning 12b gate run (paced 2.5s, healthier exit) went
  45/48 while evening batches went 3/10 and 3/5 around a Tor guard rotation.
  Every failure was an inv17/fail-closed refusal naming the empty half —
  never a fabricated comparison. Sidecar restart clears suspensions
  (in-memory); recorded as the operational remedy.

## Deviations from plan

1. **MMR (WBS 8.7) was built, suite-rejected, and withdrawn** — the plan's
   "optional MMR" shipped as `diversity=mmr` in the unreleased train, then
   suite 13b failed it on both generator seeds at every λ (alpha-nDCG gain
   only at 7–11% plain-nDCG cost; symmetric token Jaccard demotes canonical
   originals along with their shorter, higher-BM25 copies). Per the
   bench-first rule the parameter was removed before v0.3.0 released it;
   `meridian_rank::mmr` stays as the measured baseline. Replacement design
   carried to Phase 9/10: evidence-cluster diversity over ADR-18 clusters
   (the clusters already know their canonical representative).
2. **Compare jitter clamped to the request ceiling** (see honesty notes) —
   ADR-22's "default-on randomized jitter" stands, but its effective size
   under default config is disclosed in privacy.md rather than implied.
3. **MMR similarity was token-Jaccard, not embeddings** (web results carry no
   stored vectors) — recorded in the WBS row; moot after withdrawal but kept
   for the record.
4. **Phase-9 substrate landed inside the Phase-8 train** (same merge train as
   this exit, mirroring how P8 core landed in the P7 train): ADR-24 decision
   log (default OFF, `searx.decision_log`) + bandit propensity emission +
   IPS/DR estimators + suite 14 PASS (IPS bias 2.0%, DR 0.74%), plus the
   operator surface (`GET /v1/decision-log`, `POST /v1/decision-log/wipe`)
   and inv18. The v0.4.0 flag-flip and OPE-on-real-logs remain Phase 9 work.
