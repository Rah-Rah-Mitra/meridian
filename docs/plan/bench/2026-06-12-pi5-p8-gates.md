## Finding: a compare half that comes back empty must refuse, not report

The first gate attempt returned **48/48 instant compares with JSD exactly
0.0** — both halves empty because the SearXNG sidecars were down (a deploy
that recreated only `meridiand` had taken down its dependents), and
`jsd(∅,∅)=0` reads as "no divergence": fabricated agreement. Fixed in the
same train: compare now fails closed when either half has zero web results,
checking the direct half BEFORE the anon dispatch (no Tor circuit spent on a
doomed comparison). New hermetic invariant `inv17` (17 total): an empty
direct half refuses with zero anon connections.
