## Finding: a compare half that comes back empty must refuse, not report

The first gate attempt returned **48/48 instant compares with JSD exactly
0.0** — both halves empty because the SearXNG sidecars were down (a deploy
that recreated only `meridiand` had taken down its dependents), and
`jsd(∅,∅)=0` reads as "no divergence": fabricated agreement. Fixed in the
same train: compare now fails closed when either half has zero web results,
checking the direct half BEFORE the anon dispatch (no Tor circuit spent on a
doomed comparison). New hermetic invariant `inv17` (17 total): an empty
direct half refuses with zero anon connections.

## Suite 13b — MMR diversity gate: **FAIL → feature withdrawn**

Duplicate-heavy synthetic set (`meridian-eval gen-dup`): 30 queries, each an
exclusive df=3 word naming three subtopic documents, each document syndicated
as three truncation+boilerplate near-dup copies (12 matching docs > 10 slots),
5k background docs. Gate judged on the BM25-matching head (the hermetic proxy
for a query-matching web head — the syndication scenario `diversity=mmr` was
built for); the local hybrid+LTR head reported as a diagnostic. λ chosen on
seed 42, judged frozen on held-out seed 1337 (risk-#21 protocol).

| seed | head | ranking | alpha-nDCG@10 | nDCG@10 |
|---|---|---|---|---|
| 42 | BM25 (gated) | base | 0.5833 | 0.6196 |
| 42 | BM25 (gated) | MMR λ=0.7 | **0.5961** | **0.5493 (−11.3%)** |
| 1337 | BM25 (hold-out) | base | 0.5531 | 0.5802 |
| 1337 | BM25 (hold-out) | MMR λ=0.7 | **0.5855** | **0.5411 (−6.7%)** |

Verdict, replicated on both seeds across a λ sweep (0.5–0.95): the
alpha-nDCG gate passes at λ≤0.7 but the ≤1% nDCG-loss gate fails at EVERY λ —
at λ=0.95 the nDCG loss is still 2.4–2.9% and the alpha gain is gone.
**Mechanism:** token-Jaccard similarity is symmetric, so once any member of a
duplicate cluster is selected the canonical original is penalized exactly
like its copies — and because syndicated copies are shorter (higher BM25),
what falls out of the top-10 is the grade-3 original. Diagnostic regime
(hybrid+LTR head over the local corpus) is strictly worse: on exclusive-term
queries RRF interleaves the few lexical matches 1:1 with ANN noise, so any
demotion promotes an irrelevant document (nDCG −33% at λ=0.7).

**Action (bench-first rule: a failed gate does not ship):** the
`diversity=mmr` API parameter was withdrawn before v0.3.0 released it;
`meridian_rank::mmr` stays as the measured baseline. Carried forward:
evidence-cluster-aware diversity over the Phase-7 ADR-18 sketch clusters,
which knows each cluster's canonical representative instead of inferring it
from token overlap.

Harness honesty notes: three earlier runs of this suite were invalid and are
superseded — (1) copies initially reused the original title, which `build`
derives the URL from, collapsing all copies into one judged URL (the tell:
alpha-nDCG == nDCG exactly); (2) a patch applied by string-replace silently
missed and re-ran the old code; (3) the first generator allowed the query
word in ≤40 unjudged background docs and the MMR text was snippet-only where
production uses title+snippet.

## Suite 14 — OPE estimator validation (Phase-9 entry): **PASS**

`meridian-bench ope` ([json](2026-06-12-pi5-p9-ope.json)): synthetic ε-greedy
log (ε=0.1, exact emitted propensities — the shipped logging policy), 4
contexts × 3 arms, incumbent greedy arm wrong in 3 of 4 contexts, 20
replicates × 10k decisions. Candidate policy = true-best arm per context,
analytic truth 0.625.

| estimator | mean | rel. bias | gate | replicate sd |
|---|---|---|---|---|
| naive log mean | 0.3341 | −46.5% | (why OPE exists) | — |
| IPS | 0.6375 | **2.0%** | <5% PASS | 0.038 |
| DR | 0.6296 | **0.74%** | <5% PASS | 0.024 |

DR is both less biased and tighter than IPS, as ADR-25 assumed. This is the
estimator-validity precondition for the v0.4.0 ship gate (DR uplift CI
excluding zero on ≥10k live decisions).
